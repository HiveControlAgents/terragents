# Segurança

Encontrou uma falha? Abra um aviso privado em Security > Report a vulnerability, em vez de uma issue pública.

O que o TerrAgents garante hoje:
- Agentes rodam em worktrees separados, e o git deles recusa push e qualquer rede.
- Comandos que o classificador não consegue provar seguros viram decisão; o piloto automático nega por padrão.
- O servidor só aceita clientes locais, e a única página de navegador aceita é a que ele mesmo serve.
- Os tetos de custo por tarefa e por dia pausam o time; continuar depende de uma resposta humana.
