# Contribuindo

- Rode os testes antes de abrir um PR: `cd core && npm test`.
- Toda mudança no Core vem com teste quando possível.
- Commits curtos, no imperativo.
- O mod do Terraria e a página do navegador só desenham: regra de negócio fica no Core.
- Nunca commite chaves, tokens ou arquivos `.env`.
- Nada do Terraria (sprites, sons, mapas) entra no repositório.
